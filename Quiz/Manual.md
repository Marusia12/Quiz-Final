# Astrology Quiz — User Manual

## 1. Introduction

Astrology Quiz is a Java console application.
It helps users explore their zodiac sign and discover
their planetary personality archetype.

## 2. How to Start

1. Open the project in IntelliJ IDEA.
2. Open the file Main.java.
3. Click the Run button.
4. The quiz will start in the console.

## 3. How to Use the Quiz

1. Enter your date of birth.
2. Select your birth period.
3. Enter your birthplace.
4. Answer the personality questions.
5. Choose the answer that describes you best.

## 4. Quiz Results

At the end of the quiz, the application displays
your zodiac sign and planetary personality archetype.

The four possible archetypes are:

- Neptune — The Dreamer
- Mars — The Warrior
- Uranus — The Innovator
- Jupiter — The Explorer

If two archetypes receive the same score,
both can be displayed.

## 5. Requirements

- Java
- IntelliJ IDEA
