## Project Description

Astrology Quiz is a Java console application that allows users
to explore their zodiac sign and discover their planetary
personality archetype through a series of questions.

## Main Features

- Seven quiz questions.
- Multiple-choice answers.
- User input and answer validation.
- Zodiac sign identification based on date of birth.
- Questions about birth period and birthplace.
- Personality descriptions without revealing planet names.
- Planetary personality scoring system.
- Final personalized quiz result.
- Displaying the main planetary archetype.
- Showing two archetypes in case of a tie.

## Planetary Archetypes

- Neptune — The Dreamer
- Mars — The Warrior
- Uranus — The Innovator
- Jupiter — The Explorer

## Project Requirements

- Java console application.
- Code must compile and run.
- Manual explaining how to use the application.
- At least one implemented feature.
- Debugging with a breakpoint.
